### As part of my project, I used the Beautiful Soup and Selenium libraries to perform web scraping on GitHub.

It is important to note that this was solely a testing and technical experimentation phase. In a real-world production environment, several constraints must strictly be respected, notably :

- GDPR Compliance : The collection and processing of personal data (such as emails or profile information) are regulated by law, even if this data is publicly available.

- Terms of Service (ToS) : It is essential to comply with the site's robots.txt file and avoid overloading the servers (using the official API is recommended).

### This initial phase—carried out on dedicated practice websites—allowed me to assess technical feasibility while keeping in mind the legal and ethical best practices required for a finalized project.
